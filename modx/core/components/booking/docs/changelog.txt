booking 1.0.0-pl (22.10.2026)
- Первая версия: Дома, бани, цены по дням недели, праздники с особыми ценами, закрытые даты.
- Заявки гостей через SendIt (пресет booking_request), письмо администратору, MAX через MaxNotify3.
- Подтверждение, отмена, залог 5 000–20 000 ₽, бронь по телефону; защита от двойной брони.
- Админка «Пакеты → Бронирование», приложение /booking/app (PWA, мини-приложение MAX) по токену.
- «Моя заявка» и запрос отмены гостем.
- Скидка 5% — только при бронировании через ВКонтакте (галочка в брони по телефону).
- Перенос прежних заявок сайта и вывод раздела «Заявки» из работы.
