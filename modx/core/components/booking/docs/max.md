# Мини-приложение MAX

Мини-приложение — это та же страница `https://ваш-домен/booking/app`, открытая из бота MAX. В ней есть вкладки «Забронировать», «Моя заявка» и «Администратор» (по токену). Отдельных программ и отдельного API у мини-приложения нет: те же процессоры, те же проверки (конституция ст. 3.3, 7.7).

## Подключение

1. В кабинете MAX для бизнеса откройте своего бота → «Мини-приложение» (кнопка меню бота).
2. Адрес мини-приложения: `https://ваш-домен/booking/app?client=max`. Метка `client=max` пишется в журнал и в источник заявки.
3. Гостям достаточно вкладки «Забронировать».
4. Администратору: «Бронирование → Токены» → выпустить токен «MAX, <имя>» → в мини-приложении «Администратор» → вставить токен. Он хранится только на этом телефоне.

## Сообщения о заявках в MAX

Это дополнение MaxNotify3, его настройки — в «Системных настройках», раздел `maxnotify3`:

| Настройка | Значение |
|---|---|
| `maxnotify3.provider` | `maxbusiness` |
| `maxnotify3.max_api_url` | `https://platform-api2.max.ru/messages` (не менять на старый адрес — ст. 7.5) |
| `maxnotify3.max_token` | токен бота из кабинета MAX |
| `maxnotify3.max_recipient_ids` | id чатов или пользователей через запятую |

Токены нельзя записывать в файлы и в репозиторий (ст. 7.4).
