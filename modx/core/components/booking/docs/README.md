# Бронирование (booking) для MODX 3

Бронирование Домов и бань сайта «Доходные Дома Ефремовых»: календарь занятости, расчёт цены, заявки гостей через SendIt, админка «Пакеты → Бронирование», приложение для телефона (PWA и мини-приложение MAX).

## Что нужно

- MODX 3.2+, PHP 8.1+, MySQL / MariaDB (InnoDB).
- **SendIt**, **FormIt**, **pdoTools** — отправка формы бронирования (без SendIt форма не отправится).
- **MaxNotify3** (modstore.pro, бесплатный) — сообщения о заявках в MAX. Ставится без miniShop3. Необязателен: без него приходят только письма.

## Установка

1. «Пакеты → Установщик»: загрузите `booking-1.2.2-pl.transport.zip` и установите.
2. Установщик создаёт:
   - таблицы `booking_*`;
   - три Дома с ценами сайта (баня у каждого Дома есть, но отдельно не бронируется);
   - настройки `booking.*` и право `booking_admin` у администраторов;
   - пункт меню «Бронирование»;
   - страницы `/booking` (форма), `/booking/zayavka` («Моя заявка»), `/booking/app` (приложение) и `/booking/sw.js`.
3. Почта для заявок — «Конфигурация» → «Почта для заявок» (как у прежней формы сайта). Отдельный адрес только для бронирования — системная настройка `booking.admin_email`.

Повторная установка и обновление данных не теряют: таблицы только дополняются, Дома, цены и настройки не перезаписываются.

## Сайт

Пакет сайта (`bania-modx`) сам переключается на компонент, если тот установлен:
- кнопки «Оставить заявку» и блок заявки открывают форму бронирования (`[[!bnOrderForm]]` → `booking.form`);
- данные Домов для брони берутся из компонента. Это цены суток («Бронирование → Цены»), время заезда и выезда, сколько ночуют и отдыхают («Дома и бани»), норма гостей в цене и доплата сверх неё. Их меняют в одном месте, и они сразу видны в форме, на страницах Домов, в карточках и в таблице цен. Описания, фото, туры и прочие тексты Домов остаются в полях страниц Домов.

Без компонента сайт работает как раньше, с прежней формой.

Вызовы на любых страницах:

| Вызов | Что выводит |
|---|---|
| `[[!booking.form? &mode=`full`]]` | полная форма с календарём на 2 месяца |
| `[[!booking.form? &mode=`compact` &house=`ru`]]` | компактная форма, Дом выбран заранее |
| `[[booking.prices? &house=`en`]]` | цены суток по дням недели (разметка `.price-days` сайта) |
| `[[!booking.request]]` | «Моя заявка»: статус, залог, запрос отмены |

## Как это работает

- **Заявка гостя.** Через SendIt идёт статус «новая». Даты она не занимает: на одни даты может быть несколько заявок.
- **Подтверждение.** Подтверждает только администратор. Если даты пересекаются с другой подтверждённой бронью, приходит отказ с её номером. Два одновременных подтверждения не пройдут оба: строка Дома блокируется, а занятые ночи защищены ключом в базе.
- **Скидок нет**: акция «−5% через ВКонтакте» отменена (решение владельца 27.10.2026). Под формой — ссылка на группу ВКонтакте (`booking.vk_url`).
- **Залог** необязателен: 5 000–20 000 ₽, назначает администратор при подтверждении.
- **Праздники.** Цена считается по правилу:
  - предпраздничный рабочий день — как пятница;
  - праздник перед выходным — как суббота;
  - праздник перед рабочим днём — как воскресенье.

  У любого Дома на праздничную дату можно задать особую цену.
- **Баня отдельно** включается у Дома в «Дома и бани»: цена за час, минимум часов, перерыв между сеансами (30 мин). Сеанс нельзя поставить в ночь подтверждённой брони этого Дома.

## Админка: «Пакеты → Бронирование»

| Вкладка | Что в ней |
|---|---|
| Календарь | сетка «Дома и бани × даты»: подтверждённые брони (зелёные), новые заявки (кружок с числом), просьбы об отмене (оранжевые), закрытые даты; по клику — карточка |
| Заявки | список с фильтрами; «Бронь по телефону» — заявка или сразу подтверждённая бронь за гостя, ссылка гостю |
| Дома и бани | вместимость, время заезда и выезда, баня отдельно |
| Цены | цены суток, норма гостей, доплаты |
| Праздники | даты, тип, особые цены по Домам |
| Закрытые даты | ремонт и прочее: даты становятся серыми для гостей |
| Токены | вход администратора с телефона |
| Перенос заявок | перенос из прежнего раздела «Заявки» и его вывод из работы |

## Телефон: приложение и MAX

1. «Бронирование → Токены» → «Выпустить токен» и подпишите, чей телефон. Токен показывается один раз.
2. На телефоне откройте `https://ваш-домен/booking/app` → вкладка «Администратор» → вставьте токен. Его можно «Установить на экран» как приложение.
3. Потерян телефон — «Отозвать» токен.

Мини-приложение MAX — см. [max.md](max.md).

## Уведомления

- **Письмо администратору** — хук `email` пресета SendIt `booking_request`, шаблон — чанк `booking.email.request`. Запрос отмены гостем — чанк `booking.email.cancel`.
- **MAX** — своё сообщение из `booking.hook`: номер, Дом, даты, гости, сумма по строкам, имя и телефон, кнопки «Открыть в приложении» и «Открыть в админке». Хук `maxNotify3SendIt` не подключается — он присылал все поля формы подряд, включая служебные. Настройки MaxNotify3 (`maxnotify3.*`):
  - `provider` = `maxbusiness`;
  - `max_api_url` = `https://platform-api2.max.ru/messages`;
  - `max_token` — токен бота;
  - `max_recipient_ids` — кому писать.

  Токены — только в настройках, не в файлах.
- Если письмо не ушло, заявка всё равно сохраняется, а ошибка пишется в журнал MODX. Гость видит номер заявки.

## Известное

- **SendIt на вложенных страницах.** Свои скрипты SendIt подключает относительным путём `assets/components/sendit/...`. На вложенных страницах (`/booking/zayavka`, `/blog/...`) это даёт 404 в консоли, хотя формы там нет. Исправление — в системных настройках SendIt:
  - `si_frontend_js` = `/assets/components/sendit/js/web/index.js`;
  - `si_frontend_css` = `/assets/components/sendit/css/web/index.css`.

  Страница приложения `/booking/app` от этого защищена своим `<base href>`.
- **Манифест приложения** рассчитан на адрес `/booking/app`. Если переименуете страницу `/booking`, поправьте `start_url` и `scope` в `assets/components/booking/app/manifest.webmanifest`.

## Разработка

- **Исходники:** `modx/core/components/booking`, `modx/assets/components/booking`.
- **Сборка и установка на стенд:** `php _build/build.transport.php [config.core.php] --install`.
- **Модель из схемы:** `php _build/build.schema.php`.
- **Тесты:**

  | Команда | Что проверяет |
  |---|---|
  | `php _build/tests/run.php` | процессоры: цены, пересечения, права |
  | `php _build/tests/concurrency_confirm.php` | гонка подтверждений |
  | `python _build/tests/e2e_us1.py … e2e_us6.py`, `e2e_migrate.py` | браузер (Playwright, Chrome) |
