# Перенос сайта «Доходные дома Ефремовых» на MODX 3

Установщик `bn-install.php` сам делает всё внутри MODX: ставит дополнения, копирует файлы сайта, создаёт шаблоны, поля, страницы, настройки и раздел «Заявки». Нужно только поставить сам MODX и один раз открыть установщик.

Что получится в админке:
- **Ресурсы → три дома** (Английский, Русский, Свиязева): все цены, гости, заезд и выезд, галерея, удобства, вопросы, тексты — во вкладке полей дома. Внутри каждого дома — его страница предоплаты (`/Предоплата1/` и т. д., адреса как на старом сайте).
- **Ресурсы → «Блог»** — статьи. Новая статья: правый клик по «Блогу» → «Создать документ», шаблон подставится сам. Текст пишется в визуальном редакторе: каждый раздел — заголовок «Заголовок 2», по ним строится оглавление.
- **Ресурсы → «Отзывы»** — отзывы гостей для карусели на главной и на страницах домов. Заголовок — имя гостя, «Содержимое» — текст отзыва слово в слово, в полях — дом, оценка, где оставлен, дата. Только настоящие отзывы.
- **«Конфигурация»** (ClientConfig) — телефоны, ссылка на чат MAX, ВКонтакте, почта на сайте и **почта для заявок**, реквизиты, скидка за бронь на сайте, процент предоплаты, залог, повар, ссылки для отзывов, Яндекс Метрика.
- **Пакеты → «Заявки»** — все заявки с сайта: статус (новая → связались → подтверждена → выехали / отказ), предоплата, заметка, выгрузка в Excel (CSV). Заявка «Подтверждена» занимает ночи дома — вторую заявку на те же ночи подтвердить не получится. На этой таблице потом можно построить онлайн-бронирование и календарь занятости.
- **Главная → поля**: фото первого экрана, частые вопросы, правила домов, лента фото. Тексты блоков главной — Элементы → Чанки → «Доходные дома / Главная».

Где будут файлы на хостинге (установщик раскладывает сам):
```
public_html/
  core/  manager/  connectors/  index.php      ← MODX
  core/components/bania/                       ← библиотека сайта и страница «Заявки»
  assets/css/  assets/js/  assets/img/         ← стили, скрипт, фото домов, QR-коды
```

## Шаг 1. Хостинг

1. В панели хостинга у домена выберите PHP **8.2** или **8.3**.
2. Выпустите бесплатный SSL-сертификат: сайт должен открываться по `https://`.

## Шаг 2. MODX 3

Поставьте MODX 3 (в панели Beget: **CMS → Установка CMS → MODX Revolution 3.x**, или вручную с [modx.com/download](https://modx.com/download) через `https://ваш-домен/setup/`). Запишите логин и пароль администратора.

## Шаг 3. Архив сайта

Загрузите `bania-modx.zip` в корень сайта (рядом с `index.php` MODX) и распакуйте. Появится папка `bania-modx`.

## Шаг 4. Установщик

1. Войдите в админку: `https://ваш-домен/manager/`.
2. В той же вкладке откройте `https://ваш-домен/bania-modx/bn-install.php?dry=1` — **проверка**, ничего не меняется. Красных строк быть не должно.
3. Нажмите **«Установить»** (1–3 минуты: скачиваются ClientConfig и визуальный редактор).
4. В конце установщик сам проверит сайт: страницы домов, предоплаты, блог, карту сайта, файлы, приём заявок, https и почту.
5. Нажмите **«Удалить папку установщика»**.

Проверьте сразу:
- главная, страницы домов, `/Предоплата1/`, `/kontakty`, `/blog` открываются;
- отправьте тестовую заявку с сайта — она придёт на почту из «Конфигурации» и появится в **Пакеты → Заявки**.

## Шаг 5. Что заполнить после установки

- **Почта для заявок** — «Конфигурация» → «Контакты». Можно несколько адресов через запятую.
- **Заявки в Telegram** (по желанию): создайте бота у @BotFather, добавьте его в нужный чат, впишите токен и ID чата в системные настройки `bn_tg_token` и `bn_tg_chat`.
- **Ссылки для отзывов** — «Конфигурация» → «Отзывы»: ссылки на ваши карточки в Яндекс Картах и 2ГИС, под каруселью появятся кнопки «оставить отзыв».
- **Яндекс Метрика** — «Конфигурация» → «Аналитика»: номер счётчика. Отправленная заявка считается целью `lead`.
- **Политика обработки персональных данных**: создайте страницу с шаблоном `bn-text` и текстом политики — форма и подвал ссылаются на неё.

## Как работать с сайтом

**Поменять цены.** Ресурсы → дом → вкладка полей → «Цена Пн–Чт / Пт / Сб / Вс». Таблица на главной, карточки, расчёт в форме, разметка для поисковиков пересчитаются сами.

**Добавить фото дома.** «Медиа» → папка `assets/img/<код дома>/` (en — Английский, ru — Русский, sv — Свиязева) → загрузить. Затем в поле «Галерея» дома добавьте строку `имя-файла.jpg | подпись`. Порядок строк — порядок фото, **первые три строки — фото в карточке дома** (первая — главная).

**Удобства, вопросы, правила.** Одна строка — один пункт, части через `|`: `Вопрос | Ответ`, `значок | заголовок | пояснение`, `Название | значение`.

**Скидка.** «Конфигурация» → «Условия» → «Скидка за бронь на сайте». 0 — плашки скидки исчезнут.

**Отзыв.** Ресурсы → правый клик по «Отзывы» → «Создать документ». Порядок — перетаскиванием в дереве. Скрыть — снять «Опубликован».

**Тексты блоков главной** — Элементы → Чанки → «Доходные дома / Главная».

## Обновить сайт позже

1. На компьютере: `python tools/modx_build.py` → новый `dist/bania-modx.zip`.
2. Загрузите и распакуйте его (папку `bania-modx` можно заменить целиком).
3. Войдите в админку и откройте `https://ваш-домен/bania-modx/bn-install.php` → «Установить».

Обновится только изменённое. **Ваши правки не пропадут**: дома, статьи, отзывы, «Конфигурацию», заявки установщик не трогает; чанк или шаблон, который вы меняли в админке, он оставит как есть (новая версия ляжет в `core/cache/bn-install-backup/<дата>/new-versions/`).

Ключи к адресу установщика: `?dry=1` — пробный прогон, `?check=1` — только проверить сайт, `?force=1` — перезаписать и изменённое в админке, `?update=1` — перезаписать ещё и страницы версиями из архива.

## Если что-то пошло не так

- **«Нужен вход в админку»** — войдите в `/manager/` в этом же браузере и обновите страницу установщика.
- **Ошибка дополнения** — поставьте ClientConfig и «TinyMCE Rich Text Editor» вручную: «Пакеты → Установщик», затем запустите установщик снова.
- **Письма не приходят** — заявки всё равно сохраняются в «Пакеты → Заявки». Отправитель писем — `noreply@ваш-домен`; другой — системная настройка `bn_email_from`.
- **Журнал установки** — `core/cache/logs/bn-install-<дата>.log`.

Из консоли SSH: `php bania-modx/bn-install.php --dry`, затем без `--dry`.
